# Sources

Every source below is reference-only for this skill: it is read for its rules and its vocabulary, never run as its own flow. The three file sources are installed on this machine at the paths given; the fourth is an MCP server.

**frontend-design** is Anthropic's plugin skill for distinctive visual direction - the base rule layer under step 5. This skill reads its "Process: plan, review against the brief, build, critique" section (the two passes, and the five saturated-default clusters used for the review), its "Design principles" section (typography, the hero, structural devices, motion), and its "More on writing in design" section (active voice, one name per action through a flow, errors and empty states). Its build step and its self-critique loop are not run from here. Path: `skills\frontend-design\SKILL.md` inside the `installPath` recorded for `frontend-design@claude-plugins-official` in `C:\Users\<you>\.claude\plugins\installed_plugins.json`; the version folder in that path changes on every plugin update.

**Hallmark** is the anti-AI-slop page-design skill - 21 macrostructures, 21 themes, and a 58-gate slop test - vendored from github.com/Nutlope/hallmark at commit 13ac0ec7e148 under MIT (Together AI). This skill reads four files for reference: `references/macrostructures.md` for the named page shapes step 5 picks from, `references/structure.md` for the six structural axes and the structural-variety rule, `references/anti-patterns.md` for the named tells, and `references/slop-test.md` for the gate numbers cited in `gates.md`. It also reads SKILL.md's component-scope signals. This skill NEVER runs Hallmark's Design flow, its three-question design-context gate, or its build step; Hallmark's own verbs are reached only through step 1's table. Path: `{{SKILLS_DIR}}\hallmark\`.

**impeccable** is the frontend design-and-refinement skill whose Commands table owns every terminal verb on an existing surface. This skill reads section 1 of `reference/new-work.md`, "Decide what is already true" (redesign, established world, incomplete brand, no visual authority - the INHERIT/OPEN call in step 3), and `reference/craft-floor.md` (the Verify list and the Refuse list, which supply the [IMP] gates). Section 3's concept-seed tournament and the DESIGN.md write at finish are impeccable's own flow, not this skill's: step 7 here writes its own, smaller record. Path: `{{SKILLS_DIR}}\impeccable\`.

**Inspo** is the MCP evidence source - a curated archive of production sites with real fonts, frequency-ranked palettes, named macrostructures, and desktop plus mobile screenshot pairs. This skill uses five of its tools and only in step 4: `get_filters()` for valid enum values, `recommend(brief, macrostructure?, pageType?, mode?, vibe?, color?, device?)` where `mode` is the light/dark axis, `search_screens(query, ...)` with `detail: "concise"`, `get_screen(slug)`, and never `get_design_system(slug, live?)` with its default `live: true`. List tools take `maxTokens`; the cap is approximate, and the top result and all URLs always survive it. The lite profile exposes nine tools, the full profile fifteen. Hosted endpoint: `https://inspomcp.dev/api/mcp`; docs: `gh api repos/Nutlope/inspo/contents/apps/mcp/README.md --jq .content | base64 -d`.

**Also reached, not read for design.** On client-confidential work, run your own redaction gate first if you have one (step 0). The harness `dataviz` skill is a built-in with no path in this folder; step 1 hands charts to it when the session lists it. The builder spec contract this skill's block slots into lives in the model-router plugin at `skills/fabstra/references/specs.md`, under the Conventions bullet of the Blueprint.
